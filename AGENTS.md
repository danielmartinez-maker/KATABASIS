# Repository instructions

## OneDrive boundary

- This local checkout is the canonical Katabasis working copy.
- Never access, inspect, search, read, write, copy, move, or sync files in any OneDrive folder.
- Do not use OneDrive as a working directory, source, destination, or backup location.
- If a required file appears to exist only in OneDrive, stop and ask the user to provide a local copy.
- Keep project work and backups in this local repository, GitHub, or another explicitly non-OneDrive location.
